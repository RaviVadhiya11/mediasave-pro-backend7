05 Help & FAQs

  
Can I paste any Instagram Reel, YouTube or Facebook post link?
No. A social post page is not a direct media file. Use the platform's own download/export feature where available, or a file link that you own or have permission to save.

  
What is a direct media-file URL?
It is a link that points to a file such as MP4, WebM, MP3, JPG or PNG—not a profile, post page or normal webpage. MediaSave Pro checks the URL format; the original host decides whether the file can be opened or downloaded.

  
Do Video Tools upload my selected file?
No. Video conversion and PNG thumbnail creation run in your browser. Your file is processed on your device; keep the tab open while it works.

  
Why might an Instagram media card have no file link?
Meta may not provide a media URL for some Reels or videos, including certain licensed-audio or download-restricted items. MediaSave Pro will show the post link instead of trying to bypass that restriction.
