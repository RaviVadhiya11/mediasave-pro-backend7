Privacy Policy

Last updated: November 10, 2026

1. Information processed

When you submit a direct media URL, it is sent to the MediaSave Pro API hosted by Render for validation and, when requested, retrieval of the file. Your browser sends standard technical request data such as IP address and user-agent information to hosting providers.

2. Downloads and previews

When you choose Download file, the backend streams an eligible direct HTTPS media file to your browser as an attachment. The service does not intentionally keep a persistent copy. Video previews are streamed to your browser when the source permits them; a thumbnail frame is generated locally in your browser. Direct file downloads are subject to file-type, host, size and rate limits.

3. Social links

Instagram, YouTube, Facebook and Snapchat post links are identified to show official save/export guidance. This website does not scrape social-media pages, bypass logins, DRM or creator download settings, or fetch arbitrary public posts.

4. Private creator page

The optional owner page requests media from the site owner's authorised Instagram Professional account using a server-held Meta access token. The private access key is sent in an authorisation header and is not stored in local storage. Media URLs are shown only when Meta returns them. Selected files are streamed to the browser, not kept in a persistent archive.

5. Local browser storage

The website may store your theme preference and recent activity labels/timestamps in local storage on your device. It does not intentionally store media files or submitted media URLs in this history. Clear browser site data to remove local preferences and history.

6. Third-party services

The website is hosted on GitHub Pages and its API is hosted on Render. When you open an external platform or direct media source, that provider's privacy policy applies. Review provider privacy terms separately.

7. Contact

For privacy questions, use the Contact page. Do not send access tokens or passwords.
