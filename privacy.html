Privacy Policy.

How MediaSave Pro handles information when you use its media tools.

Last updated: November 10, 2026

1. Information you provide

MediaSave Pro does not require visitors to create an account to use the public direct-link and browser video tools. If you paste a direct media URL, the URL is sent to the MediaSave Pro API hosted on Render for validation. When you choose Download file, the API requests the direct HTTPS media file from its original host and streams it to your browser as an attachment. The service does not keep a persistent copy. Direct downloads are limited to supported media file types, publicly resolvable HTTPS hosts and 100 MB per request; source hosts may reject requests.

2. Video tools

Video compression/conversion and thumbnail creation run locally in your browser using your device's browser capabilities. The selected video file is not uploaded to MediaSave Pro by these tools. Your browser may keep temporary in-memory or local object URLs while the page is open; close the page to release them.

3. Instagram creator media

The separate My Media page is intended only for the site owner's authorized Instagram Professional account. The Meta access token is stored as a secret environment variable on the backend, not in the public website files. The private access key is sent to the backend in an authorization header when the owner requests media; the website code does not save it to local storage.

4. Hosting and technical logs

The website is delivered through GitHub Pages and the API runs on Render. Those providers may process technical information such as IP address, request time, browser details and service logs as part of hosting, security and operations. Please review their own privacy notices for details.

5. Third-party websites

When you open a direct media URL or an Instagram post, you leave MediaSave Pro and interact with the source provider. That provider's privacy policy and terms apply to your use of its service.

6. Cookies and analytics

The site stores your selected dark/light theme and up to 30 recent tool-action labels and timestamps in this browser's local storage. It does not store video files or direct media URLs in that history. The current version does not intentionally set advertising cookies or run an analytics tracker. Hosting providers may use essential technical mechanisms. If analytics or advertising is added later, this policy must be updated before launch.

7. Children's privacy

MediaSave Pro is a general utility website and is not designed to collect personal information from children. Do not submit personal or sensitive information through media links or support requests.

8. Contact and requests

For privacy questions or requests, use the Contact page. Do not include access tokens, passwords, private keys or other credentials in a support request.
