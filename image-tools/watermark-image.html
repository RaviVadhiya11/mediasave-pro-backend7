About watermark image

Place a custom text watermark on your image. Choose its text, colour, opacity, size and position, then export a new copy without changing your original file. PixelNest runs this task inside your web browser using standard image and canvas features. That means your selected image file is not uploaded to a PixelNest processing server. Processing speed and maximum image dimensions depend on the memory and capabilities of your phone or computer.

Supported input formats vary by browser. JPG, PNG and WebP are the safest choices. Some devices can also decode other formats, but unsupported file types may not open. Keep a backup of your original image before editing.

Frequently asked questions

Can I remove a watermark later?

The exported watermark is merged into the image. Keep your original copy if you may need to edit it.

Can I add a logo image?

This first version adds text watermarks. Image-logo overlays are not included yet.
