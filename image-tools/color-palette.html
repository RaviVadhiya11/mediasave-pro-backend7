About color palette extractor

Sample an image in your browser and identify a set of representative colours. Copy HEX codes to use in design, branding, presentations or web projects. PixelNest runs this task inside your web browser using standard image and canvas features. That means your selected image file is not uploaded to a PixelNest processing server. Processing speed and maximum image dimensions depend on the memory and capabilities of your phone or computer.

Supported input formats vary by browser. JPG, PNG and WebP are the safest choices. Some devices can also decode other formats, but unsupported file types may not open. Keep a backup of your original image before editing.

Frequently asked questions

Are the colours exact brand colours?

They are sampled representative colours, not a guarantee of an official brand palette.

Can I use the colours in CSS?

Yes. Copy a HEX code and paste it into your CSS or design application.
