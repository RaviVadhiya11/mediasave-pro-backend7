IMAGE FORMAT GUIDE

JPG, PNG, WebP and more: image formats explained

Different image formats are designed for different jobs. Some are ideal for photographs, some preserve transparency, and others are designed for web delivery or professional image workflows. PixelNest can convert many common formats, but actual input support depends on the browser and the file variant.

Common image formats

  • JPG / JPEG: a widely supported lossy format for photographs. JPG and JPEG are the same format. It does not store transparency.
  • PNG: lossless raster format that supports transparency. Useful for logos, screenshots and graphics with sharp edges.
  • WebP: modern web image format that supports lossy/lossless compression and transparency. Useful for web photos and graphics.
  • AVIF: modern image format with strong compression and transparency support. Decoding is available in many modern browsers; encoding through canvas is browser-dependent.
  • BMP: simple bitmap format. PixelNest can create uncompressed BMP output; files can be much larger than JPEG or WebP.
  • GIF: can contain animation. The current PixelNest canvas tools decode a still frame and do not preserve animated GIF frames when exporting.
  • SVG: vector image format. The browser can render many SVG files, then PixelNest can rasterize them into PNG, JPG, WebP or other supported output formats. External resources inside SVG can prevent canvas export.
  • HEIC / HEIF: common on some phones. PixelNest loads an optional browser-side decoder to convert HEIC/HEIF to a canvas image; some multi-image bursts may be reduced to the main image.
  • TIFF: used in publishing and photography. PixelNest uses a browser-side decoder for TIFF input and can export uncompressed TIFF. Large TIFF files may use significant memory and storage.

Which formats can PixelNest open?

Native browser formats such as JPEG, PNG, WebP, GIF, BMP, SVG and AVIF are supported where the browser can decode them. HEIC/HEIF and TIFF are supported through optional libraries downloaded from a public CDN. JXL, ICO and some unusual variants remain browser-dependent. RAW camera files such as DNG, CR2 and NEF are not fully developed into display-ready photographs by this release.

Which formats can PixelNest export?

Current output choices are JPG/JPEG, PNG, WebP, BMP and TIFF. AVIF is also offered, but the browser must support AVIF canvas encoding; if it does not, PixelNest will show an error instead of silently saving a PNG with an AVIF extension. TIFF output is uncompressed and may be large. Canvas tools create still images and do not preserve animation.

Examples: JPG to PNG and PNG to JPG

To convert JPG to PNG, open the Image Converter, choose a JPG/JPEG photo and select PNG as the output format. The PNG file will be created from the pixels decoded by your browser. To convert PNG to JPG, choose JPG/JPEG as the output format; transparent pixels are filled with white because JPEG does not support transparency.
