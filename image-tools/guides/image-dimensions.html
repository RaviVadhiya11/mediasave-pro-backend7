How to Choose Image Dimensions for Websites and Mobile

A straightforward guide to choosing responsive image dimensions and keeping photos sharp on mobile screens.

Start with the display size

Image dimensions are measured in pixels. Before resizing a photo, consider the space where it will appear: a small avatar, a product thumbnail, a blog image or a large banner. Exporting a very large image for a tiny display can waste bandwidth, while exporting a very small image for a large area can make it look soft.

Keep the aspect ratio

The aspect ratio is the relationship between width and height. A 1600 × 900 image has a 16:9 ratio; a 1000 × 1000 image is square. When you resize proportionally, both dimensions change together and the subject does not become stretched. If a design requires a different ratio, crop the image instead of distorting it.

Choose dimensions for the use case

For profile pictures, square crops are common. For video thumbnails and presentation covers, 16:9 is common. For portrait social posts, use the dimensions requested by the destination platform. Platform specifications can change, so check the current upload guidance when exact requirements matter.

Consider high-density screens

Some screens have a higher pixel density than others. A source image may need more pixels than the CSS display width to appear crisp on those screens. However, sending unnecessarily large files to every visitor can slow a page. Responsive image markup and appropriately sized variants help websites serve a better-sized file for each screen.

Resize or crop?

Use resize when you want to preserve the whole image and change its overall pixel dimensions. Use crop when you need to change the framing or remove unneeded edges. Do not enlarge a small original expecting it to gain real detail; interpolation only estimates pixels between the ones already present.
