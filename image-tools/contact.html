SUPPORT

Contact & feedback

PixelNest Tools is an independent project. For a technical issue, include the tool name, your phone/browser model and the error message. Do not attach private or sensitive photos to a public issue.

Report a problem

Use the project's GitHub issue tracker to report a bug or suggest a feature. Please do not include passwords, identity documents or other private information.

Open support issue ↗

Feature requests

Useful suggestions include better batch handling, more output presets, crop ratios, keyboard accessibility and additional local image utilities. Advanced AI tools may require a model download or server budget and are not part of the current release.
