Privacy Policy

Last updated: November 10, 2026

1. Image processing

The tools in this release use your browser's built-in image and canvas features to read the file you select and create a new image copy. The selected image file is not intentionally uploaded to a PixelNest file-processing server. Files and output blobs remain in your browser session unless you download them to your device.

2. Browser capabilities

Processing performance and supported image formats depend on your browser, operating system, available memory and device. The current tools do not provide server-side AI processing. Some image formats, animated images or very large files may not be supported or may use significant device memory.

3. Technical information

GitHub Pages hosts the site files. The hosting provider may process standard technical information such as IP address, browser details and request logs to deliver the website. This site does not currently use a PixelNest account system, image upload API, analytics tracker or advertising cookies.

4. Third-party services

The CSS uses system fonts and does not require an external font download. Links to external websites are clearly identifiable; their own privacy policies apply when you visit them. Hosting and browser services may have their own technical logs.

5. Your responsibility

Do not use this service to process images unlawfully or upload images you do not have rights to use. Avoid using shared or public devices for sensitive photos. Clear your browser's site data and downloads when appropriate.

6. Changes

This policy may be revised when new services such as analytics, advertising or server-based features are introduced. Any future data collection should be described before those features are enabled.

7. Contact

For privacy questions, use the Contact page. Do not post sensitive personal information in public issue reports.
