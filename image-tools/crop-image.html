HOW TO USE THIS TOOL

Crop Image in three steps

  1. Select a photo to show its original width and height.
  2. Enter the left, top, crop width and crop height in pixels.
  3. Press Crop image and download the cropped photo.

About crop image

Crop an image by entering the crop position and dimensions in pixels. The preview updates locally and the resulting image can be saved as PNG, JPEG or WebP. PixelNest runs this task inside your web browser using standard image and canvas features. That means your selected image file is not uploaded to a PixelNest processing server. Processing speed and maximum image dimensions depend on the memory and capabilities of your phone or computer.

Supported input formats vary by browser. JPG, PNG and WebP are the safest choices. Some devices can also decode other formats, but unsupported file types may not open. Keep a backup of your original image before editing.

Frequently asked questions

Does cropping stretch the picture?

No. The selected rectangle is copied at its original pixel size.

Can I crop a batch?

The current crop tool processes selected files with the same pixel crop area.
